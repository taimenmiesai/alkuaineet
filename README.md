# Alkuaineiden ihmeellinen maailma 🧪

Interaktiivinen sivu, joka opettaa alkuaineita lapselle (noin 9-vuotiaalle) selkeällä suomen kielellä.

## Mitä sivulla on

- **Mikä on alkuaine?** Atomi, protonit, neutronit ja elektronit kuvan kera. Pääasia: protonien määrä ratkaisee, mikä alkuaine on.
- **Alkuainetaulukko.** Kaikki 118 alkuainetta. Kun ruutua klikkaa, aukeaa kortti, jossa on
  - liikkuva atomin kuva (ydin + elektronikuoret)
  - protonien, neutronien ja elektronien määrä
  - hauska tieto
  - olomuoto huoneenlämmössä
  - mistä alkuaine on peräisin
  - Värityksen voi vaihtaa: *Ryhmät* tai *Mistä alkuaine tuli?*. Mukana on myös haku.
- **Miten alkuaineet syntyivät?** Kuuden kohdan tarina: alkuräjähdys → tähdet → supernovat → neutronitähdet → Maa → laboratoriot. Lisäksi fuusiokokeilu (vety → helium → hiili → happi → rikki).
- **Rakenna oma atomi.** Lisää tai poista protoneja ja katso, miten alkuaine muuttuu.
- **Aurinkokunta.** Klikattavat planeetat, Kuu ja Pluto. Kortissa ovat koko, etäisyys, vuoden pituus, kuut, lämpötila, hauska tieto, ainesosat (linkit alkuainetaulukkoon) ja avaruusjärjestöjen sekä -yhtiöiden tutkimusmatkat (NASA, ESA, JAXA, Kiina, Intia, SpaceX, Blue Origin, ICEYE). Matkoille on merkitty, ovatko ne käynnissä, tulossa vai historiaa. Tilanne on päivitetty marraskuussa 2026.
- **Avaruushistoria.** Aikajana Sputnikista ja Laika-koirasta kuulentoihin ja Artemis II:een.

## Käyttö

Sivu on yksi tiedosto, `index.html`, eikä se tarvitse ulkoisia riippuvuuksia. Avaa se selaimessa.

### GitHub Pages

Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
Sivu tulee osoitteeseen `https://taimenmiesai.github.io/alkuaineet/`.

## Huomioita

- Atomien kuvat on yksinkertaistettu (Bohrin malli). Oikeasti elektronit ovat ytimen ympärillä pilvenä.
- Kohta "Mistä alkuaine tuli?" näyttää kunkin alkuaineen tärkeimmän syntytavan. Moni alkuaine on syntynyt usealla tavalla.
- Neutronien määrä on laskettu alkuaineen yleisimmästä tai pysyvimmästä isotoopista.
